# Retail Sales ETL Pipeline

## About the Project

This is a beginner-level Data Engineering project
that demonstrates an ETL pipeline using PySpark and
Databricks.

## Data Flow

CSV
↓
PySpark
↓
Data Cleaning
↓
Data Transformation
↓
Delta Table
↓
SQL Analysis

## Technologies

- Python
- PySpark
- SQL
- Databricks
- Delta Lake

## Data Cleaning

- Handled missing quantity values
- Standardized product names
- Checked the dataset structure

## Data Transformation

- Calculated total sales
- Selected required columns
- Created an analytics-ready dataset

## SQL Analysis

- Total revenue
- Revenue by category
- Revenue by product
